## VYBE 0.12.2

### Clean uninstall and reinstall
- Disabled Android Auto Backup and automatic cloud restore for VYBE.
- Disabled OEM device-to-device restoration of VYBE app state.
- Disabled retained-data uninstall behavior.
- Reinstalling now starts with empty listening stats, Listening Again, cached discovery, playback queue, and app cache.
- Manual account backup remains available and is restored only after explicit sign-in and user confirmation.
