## VYBE 0.10.5

### Added
- Exact minute-level overnight update hours during onboarding, from About, and through a one-time upgrade prompt.
- Embedded video playback inside the artwork area, with current-position handoff and player controls.
- Pull-to-refresh discovery and expanded Settings search coverage.

### Fixed
- More reliable in-app Spotify sign-in across Android WebView variants, plus verified playlist sync after authorization.
- Exact shared YouTube Music IDs now restore the original title, artist, and high-resolution artwork.
- Quick Picks change each session, recommendations refresh, and Trending preserves YouTube Music chart order.
- Ambient recognition captures a longer normalized sample and tries multiple fingerprint windows.
- The notification/status-bar VYBE mark now fills Android's icon slot more clearly.
- Automatic update alerts respect the selected overnight schedule; manual checks remain immediate.

### Package
- Modern Android devices only (`arm64-v8a`).
- Android version code: `10500`.
